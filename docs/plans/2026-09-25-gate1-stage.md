# Gate 1 Stage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use minipowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add pipeline stage 4, `gate1`: compute one statistic per bias parameter per PM from the engine's tables, aggregate per asset class into a neutral baseline and a separation and recovery test, block the pipeline on a synthetic failure, report real seeds without blocking, and write `gate1_pm` and `gate1_cells` plus run metadata.

**Architecture:** `gates/gate1/inputs.py` builds one frozen `PmInputs` per PM (its rows, the rebuilt `Series` per idea, the seed's `MarketView`). Eight estimator modules in a registry each turn `(PmInputs, days, knobs)` into an `Estimate`. `aggregate.py` turns estimates into per-group `CellStats`; `verdict.py` turns stats into `Gate1CellRow` with a verdict. Only `gates/gate1/stage.py` touches the `DataStore`; a new `Stage.verdict` hook raises after run metadata is written.

**Tech Stack:** Python 3.13, numpy, scipy (`spearmanr`, `pearsonr`), pydantic v2, pytest, ruff, uv.

## Decisions made while planning (binding)

1. **Probe evidence.** A scratch run of every estimator on the committed default run (132 direct-asset PMs) matched every engine counter exactly and gave the verdict pattern recorded in Task 10. Thresholds below come from it.
2. **Loss-side opportunity set** is: `pnl_state == loss`, `trigger_pending` false, `action != roll`, `date != last horizon date`. This is exactly the engine's `loss_side_untriggered_days` count (verified per PM on the default run).
3. **Disposition `n`** is the number of position-day rows dated on a sell date (any row with action in `cut`, `trim`, `exit`, the last horizon date included); it equals the engine's `sell_day_position_days`. Flat rows count in `n` but not in the ratio.
4. **`entries_after_run`** recomputed as `bullish_sign * side_sign * view.trailing_move(series, t, H) > view.sd_h(series, t, H)` on the rebuilt series equals the engine's count per PM.
5. **Series rebuild** (binding code in Task 3) reproduces the engine's series for every idea on the default run.
6. **n_min values** are the ceiling of `16 p0 (1 - p0) / (p1 - p0)^2`: exit_deficiency 7 (0.06 vs 0.44), loss_aversion 16 (0.10 vs 0.40), herding 14 (0.17 vs 0.58), anchoring 29 (0.20 vs 0.50).
7. **Planted value for split rows** is the trait's sampled `value` for every split; the `after` window of a drift PM is compared against that same number. Accepted because split rows never enter a verdict.
8. **`stated_conviction`** for the conviction estimator comes from the idea's first ledger row on the entry date (public), not the hidden `ideas.conviction`.

- Binding algorithm for `series_for_idea` (it inverts the ledger-side rule `buy iff side_sign * bullish_sign * coeff * leg_bullish > 0`):

```python
def series_for_idea(idea: Idea, adapter: Adapter) -> Series:
    """The level series an idea trades, rebuilt from its public legs."""
    if idea.expression == Expression.OUTRIGHT:
        return adapter.outright_series(idea.instrument_id)
    bullish_sign = adapter.series(idea.expression, ()).bullish_sign
    side_sign = 1 if idea.side == Side.BUY else -1
    refs = []
    for leg in idea.legs:
        unit_ref = LegRef(leg.instrument_id, leg.tenor, 1.0)
        leg_sign = 1 if leg.side == Side.BUY else -1
        sign = leg_sign * side_sign * bullish_sign * adapter.leg_bullish(unit_ref)
        refs.append(LegRef(leg.instrument_id, leg.tenor, leg.weight * sign))
    return adapter.series(idea.expression, tuple(refs))
```

Outright uses `outright_series` because an idea's outright leg drops the tenor the position tracks (commodity M1, sovereign 10Y).

- Binding definitions (with `H = inputs.horizon_days`, `t = inputs.day_index[date]`, `s = inputs.series[idea_id]`, `side_sign` +1 buy, -1 sell):
  - anchoring: discretionary exits = rows with `date in days`, `action == exit`, `date != last_date`, `(trade_idea_id, date) not in inputs.acted`, `anchor_level` not None, and `anchor_level` not equal to the idea's `target_level` (`math.isclose(..., rel_tol=1e-9, abs_tol=1e-9)`); exit level = `idea.entry_level + s.bullish_sign * side_sign * row.pnl_unit`; inside when `abs(exit_level - anchor_level) <= knobs.anchor_band_k * view.sd_h(s, t, H)`; `value` = share inside; `n` = number of such exits.
  - extrapolation: ideas with `entry_date in days`; after-run when `s.bullish_sign * side_sign * view.trailing_move(s, t, H) > view.sd_h(s, t, H)`; `value` = share after-run; `n` = number of ideas; `pairs` = `(s.bullish_sign * side_sign, trailing_move / sd_h)` per idea. `after_run_count` returns the numerator.
  - herding: ideas with `entry_date in days` whose `view.street_view(idea.instrument_id, t)` is `overweight` or `underweight` (None and neutral skipped); agree when (overweight and side buy) or (underweight and side sell); `value` = share agreeing; `n` = number of such ideas. Uses no hidden column.
